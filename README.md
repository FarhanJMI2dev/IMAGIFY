
# Project Title

A Full Stack AI image Generation SaaS application.The Platform enbles user authentication,
prompt-to-image creation powered by the clipdrop API and seamless credit-based monetization system 
integrated with Razorpay


## Tech Stack

**Frontend:** React.js with vite, TailwindCSS, 

**Backend:** Node.js, Express.js

**Database:** MongoDB is used for records,transaction history.


## Features

**User Authentication:** Secure registration and login flow.

**AI Image Generation:** Turn text prompts into high-quality images via Clipdrop API integration.

**Credit System:** Automatic deduction of user credits per image generated.

**Monetization & Payments:** Purchase credit top-up plans via Razorpay payment gateway.

**Automated Webhooks:** Real-time database update in MongoDB upon backend transaction verification.


## Installation

Install my-project with npm

client
```bash
  npm install 
  npm run server
```
server
```bash
  npm install 
  npm start server
  
```
